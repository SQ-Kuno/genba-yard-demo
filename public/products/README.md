# 商品画像の置き場所

商品IDをファイル名にして JPEG を置くと、イラストの代わりに自動で表示されます（再読み込みのみ・コード変更不要）。

| ファイル名 | 使われる場所 |
|---|---|
| `<商品ID>.jpg` | 一覧・カード・詳細の1枚目（白〜薄いグレー背景の単体写真） |
| `<商品ID>-2.jpg` | 詳細の2枚目（特長・別アングル） |
| `<商品ID>-3.jpg` | 詳細の3枚目（同梱品） |

- 正方形（1:1）・1200×1200px 程度・200KB 以下を推奨。背景は #F4F4F2 付近の薄いグレーか白。
- PNG や別名を使いたい場合は `src/data/products.js` の商品に `images: ['xxx.png', 'xxx-2.png']` を足す。
- 商品IDの一覧: kn-id180 / kn-dd180 / kn-cs165 / kn-gd100 / kn-kb185 / kn-kc18q / kn-kv180 / nd-lx4g / nd-dm50 / nd-ct300 / bs-rs38 / bs-ws16 / bs-tb500 / gl-wl5000 / gl-hs2 / gl-hv01
- 実在メーカーのロゴ・製品写真は使わないこと。
